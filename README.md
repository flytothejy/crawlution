# Crawlution (가제)

곤충 진화 스네이크 — 애벌레로 시작해 먹고, 감싸고, 탈피하며 최종 곤충까지 진화하는 io 스타일 게임.

현재 단계: **2판 시험판** (8분 한 판, 점수 순위, 봇 상대 아레나)

- 크롤러 = 역할 5 · 계열 10 · 종 40. 들어가기 전에 계열·종·기술 형태(3가지)·특성 2칸(공용 1 + 계열 전용 1, 모두 얻는 것/잃는 것이 함께)을 고른다(시험판은 40종 모두 열림)
  - 방어: 장수풍뎅이·사슴벌레 / 돌격: 사마귀·잠자리 / 사격: 말벌·노린재 / 함정: 거미·개미귀신 / 지원: 꿀벌·반딧불이
- 판 안 성장: 먹이로 **영양**을 모아 레벨 1~16. 레벨업마다 카드 3장 중 1장(새 능력·능력 강화·주 기술 강화·보조 기술 강화, 능력 4칸 × 3레벨)
  - 진화 3단계: 레벨 1 어린 모습 → 5 성충(보조 기술 고르기: 계열 전용 1 + 공용 2) → 10 각성(주 기술·필살기에 각성 효과)
- 버튼 4개: 질주 · 웅크리기 · 주 기술 · 보조 기술. 필살기 게이지(0~100)가 차면 주 기술 버튼이 **필살기**로 바뀐다(0.5초 바닥 예고, 한 대상에 최대 체력 40%까지)
- 본능: 종마다 다른 고유 패시브 40개(기도 자세, 꽃 흉내, 물 위 걷기, 가짜 신호 …)
- 싸움: 머리로 상대 몸을 물면 피해. 꼬리 끝은 급소. 한 바퀴 감싸면 압착. 레벨이 3 이상 높은 몸에 박으면 반동
- 먹이: 작은 먹이·큰 먹이·잔해(모은 영양의 30%, 내가 레벨이 높으면 절반)·황금 꿀방울(다시 뽑기 +1)·특별 먹이 10종(계열마다 좋아함·싫어함)
- 목숨 3개: 쓰러져도 레벨·카드·진화 단계는 그대로, 길이 절반 · 모으던 영양 · 필살기 게이지를 잃는다
- 봇 20마리: 성격 4가지(사냥꾼·수집가·싸움꾼·겁쟁이), 카드 점수 규칙, 기술 형태별 쓰는 조건, 중간 참여는 판 평균 레벨 −2
- 천적 6종(3초 전 경보), 맵 3종(풀밭·모래밭·낙엽 숲), 효과음·진동, ⚙️ 설정(아들 모드는 **출시 전 삭제**)
- 기획서: '캐릭터·성장 2판', '10계열 · 종 목록', '공용 목록 · 수치', '기술 수치표', '화면 · 연출 · 봇' 탭

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 게임 로직 자동 점검(화면 없이)
npm run build    # dist/index.html 한 파일로 빌드
npm run codex    # 크롤러 도감 dist-codex/codex.html 한 파일로 빌드(능력치·기술·보조·필살기·본능·특성·카드 + 기술 모션 재생)
npm run balance -- 20   # 8분 판 20개를 화면 없이 돌려 '수치를 맞추는 방법' 표의 목표(각성 시각·판 끝 레벨·싸움 시간·필살기 횟수 …)를 잰다
npm run duel -- 12 8    # 같은 레벨(8) 1:1 대결, 계열 쌍마다 12판 → 계열·역할별 승률
npx tsx scripts/mapsize.ts 6 3300,2700,2300,2000   # 맵 반지름별 붙는 횟수·싸우는 시간·몰매 비율(먹이 밀도는 같게)
npx tsx scripts/traits.ts 12 9000   # 공용 특성마다 판 안 순위 차이(곤충 21마리에게 나눠 주고 비교)
npx tsx scripts/traitduel.ts 32 8   # 특성마다 1:1 거울 대결 승률(같은 종·형태, 한쪽만 특성)
npx tsx scripts/codex-data.ts 8 > /tmp/m.json   # 도감 실측값(기술 피해·효과, 계열 1:1 승률). 특성 결과와 합쳐 src/codex/measured.json
node scripts/shots.mjs  # 미리보기 서버(npx vite preview --port 4173)를 켠 뒤 휴대폰 크기 화면을 차례로 찍는다(FAM=spider 처럼 계열 지정)
```

시험용 주소 옵션: `?level=10`(레벨 10으로 시작), `?local=1`(시뮬레이션을 메인 스레드에서 돌림)

## 조작

- PC: 마우스 방향 · 왼쪽 클릭/스페이스 질주 · Shift 웅크리기 · E/오른쪽 클릭 주 기술(필살기) · Q 보조 기술 · 1~4 카드 · R 다시 뽑기
- 모바일: 화면 끌기(조이스틱) · 질주/웅크리기/주 기술/보조 기술 버튼 · 카드 누르기

## 구조

- `src/shared/` — 게임 로직(시뮬레이션). 화면을 모르며 Web Worker·서버·테스트에서 그대로 돈다.
  - `config.ts` 밸런스 값, `species.ts` 역할·계열·종·기술 형태·보조 기술·필살기·특별 먹이 데이터, `cards.ts` 능력 카드 37장·특성 12개, `skills.ts` 기술 구현(주 기술 30·보조 20·필살기 10·장판·부른 벌), `combat.ts` 공통 공식, `sim.ts` 시뮬레이션(레벨·진화·카드·피해·본능), `enemies.ts` 천적 6종, `bot.ts` 봇·왕지네 AI, `rng.ts` 시드 고정 난수
- `src/client/` — 화면(PixiJS)과 조작. 시뮬레이션이 보낸 상태를 보간해서 그리기만 한다. `sfx.ts` 효과음·진동
- `test/` — 로직 자동 점검

## 글꼴

Jua, Black Han Sans (Google Fonts, SIL Open Font License 1.1). 게임에서 쓰는 글자만 남겨 `src/client/fonts/`에 넣었다.
문구나 종 이름을 새로 쓰면 원본 TTF를 받아 `python3 scripts/subset-fonts.py <원본 폴더>`를 다시 돌린다.
