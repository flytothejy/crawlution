# Crawlution (가제)

곤충 진화 스네이크 — 애벌레로 시작해 먹고, 감싸고, 탈피하며 최종 곤충까지 진화하는 io 스타일 게임.

현재 단계: **프로토타입 C** (8분 한 판, 점수 순위)

- 5단계 · 5갈래(갑옷·사냥·무리·독·거미), 애벌레 포함 21종, 종마다 다른 스킬
- 체력 싸움: 머리로 상대 몸을 **물면** 체력이 깎이고 꼬리 마디가 떨어진다. 체력 0이면 쓰러짐
- 피해 배수 = 단계 차이(1단계당 ±25%) × 상성(유리 1.1배, 불리 0.92배, 약하게). 각 갈래는 2승 2패
- 강한 상대 몸에 박으면 튕겨 나며 반동 피해. 웅크리기(살금)는 느려지는 대신 받는 피해 절반
- 갈래 능력치(species.ts LINEAGE): 갑옷 체력 1.3배·받는 피해 -15%·느림 / 사냥 물기 1.25배·빠름·체력 0.85배 / 무리 회복 2.2배·성장 1.2배 / 독 기술 1.2배·물면 중독 / 거미 기술 재사용 0.8배·물면 느려짐
- 감싸기: 내 몸으로 한 바퀴(약 35마디부터) 감싸면 1초 뒤 고리 안 곤충을 압착(한 방 필살기)
- 목숨 3개: 쓰러지면 단계는 그대로, 길이 절반으로 3초 무적 부활
- 길이 제한 없음: 길수록 성장이 느려지고 몸이 굵어진다
- 탈피 카드 3장(주변 상성 정보 표시) · 같은 갈래로 이어 가면 숙련(스킬 쿨다운 감소)
- 한 판 8분, 끝나면 점수 순위로 결과. 봇 20마리(판 시작은 모두 애벌레)
- 맵 3종(풀밭·모래밭·낙엽 숲), 바위(튕김)·웅덩이(느려짐)
- 천적 6종이 차례로 나타남(3초 전 경보): 새(그림자 급강하), 개구리(혀), 소나기(빗방울), 왕지네(1등 추격, 잡으면 +1500), 개미핥기(띠 핥기), 채집망 든 아이(잡히면 5초 갇혔다가 반쪽으로)
- 약자의 한 방: 꼬리 끝을 물면 급소(상대 최대 체력 15%), 강한 적에게 맞으면 역습 게이지 → 다음 공격 +30%
- 5단계에서도 게이지가 차면 다른 갈래 5단계로 변신하거나 같은 종 강화(★, 최대 5)
- 보석(능력치 성장): ❤ 체력 +6% · 🦷 공격 +6% · ⚡ 속도 +2% · ✨ 기술 피해 +6%·재사용 -2.5% (레벨마다, 최대 10). 쓰러지면 보석 레벨의 절반을 떨어뜨림
- 특별 먹이 5종: 갈래마다 하나씩 좋아하고 하나씩 싫어함. 좋아하면 폭풍 성장(게이지 +30, 마디 +8, 체력 30% 회복), 싫어하면 4초 동안 느려짐
  - 🍑 과일(갑옷♥ 사냥✖) · 🍖 고깃점(사냥♥ 거미✖) · 🍯 꿀(무리♥ 독✖) · 🍄 독버섯(독♥ 무리✖) · 🦟 모기(거미♥ 갑옷✖)
- 효과음(WebAudio 합성, 파일 없음)·진동(지원 기기만)
- ⚙️ 설정(시작·결과 화면, 게임 중 버튼; 여는 동안 게임 멈춤, 기기에 저장): 아들 모드(내 곤충 5배, **출시 전 삭제**), 다른 곤충 수, 맵, 버튼 위치(왼손잡이)·크기, 효과음·음량·진동, 화면 흔들림·피해 숫자·이름표·갈래 분포·화질

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 게임 로직 자동 점검(화면 없이)
npm run build    # dist/index.html 한 파일로 빌드
npm run balance -- 1 8 > out.json   # 시드 1부터 8판을 화면 없이 돌려 밸런스 기록
node scripts/balance-report.cjs out.json   # 진화 속도·단계 분포·싸움 양상 요약
npx tsx scripts/species.ts field 1 8 > field.json     # 종별 실전 통계(피해·막은 피해·기술 1회당 피해·처치:쓰러짐)
npx tsx scripts/species.ts duel 1 80 > duel.json      # 같은 단계 1:1 대결 승률표
npx tsx scripts/species.ts ablate 1 200 > ablate.json # 기술 켜고/끄고 같은 종끼리 → 기술 자체의 가치
node scripts/species-report.cjs field.json duel.json ablate.json
```

시험용 주소 옵션: `?stage=3`(3단계로 시작), `?local=1`(시뮬레이션을 메인 스레드에서 돌림)

## 조작

- PC: 마우스 방향 · 왼쪽 클릭/스페이스 부스트 · Shift 살금 · E/오른쪽 클릭 스킬 · 1/2/3 탈피 카드
- 모바일: 화면 끌기(조이스틱) · 부스트/살금/스킬 버튼 · 카드 누르기

## 구조

- `src/shared/` — 게임 로직(시뮬레이션). 화면을 모르며 Web Worker·서버·테스트에서 그대로 돈다.
  - `config.ts` 밸런스 값, `species.ts` 갈래·종·스킬 데이터(곤충 추가 = 데이터 한 덩어리), `combat.ts` 피해 공식, `sim.ts` 시뮬레이션, `enemies.ts` 천적 6종, `bot.ts` 봇·왕지네 AI, `rng.ts` 시드 고정 난수
- `src/client/` — 화면(PixiJS)과 조작. 시뮬레이션이 보낸 상태를 보간해서 그리기만 한다. `sfx.ts` 효과음·진동
- `test/` — 로직 자동 점검

## 글꼴

Jua, Black Han Sans (Google Fonts, SIL Open Font License 1.1). 게임에서 쓰는 글자만 남겨 `src/client/fonts/`에 넣었다.
문구나 종 이름을 새로 쓰면 원본 TTF를 받아 `python3 scripts/subset-fonts.py <원본 폴더>`를 다시 돌린다.
