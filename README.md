# Crawlution (가제)

곤충 진화 스네이크 — 애벌레로 시작해 먹고, 감싸고, 탈피하며 최종 곤충까지 진화하는 io 스타일 게임.

현재 단계: **프로토타입 C** (완성된 한 판)

- 5단계 · 5갈래(갑옷·사냥·무리·독·거미), 애벌레 포함 21종, 종마다 다른 스킬
- 체력 싸움: 머리로 상대 몸을 **물면** 체력이 깎이고 꼬리 마디가 떨어진다. 체력 0이면 쓰러짐
- 피해 배수 = 단계 차이(1단계당 ±35%) × 상성(유리 1.5배, 불리 0.6배). 각 갈래는 2승 2패
- 강한 상대 몸에 박으면 튕겨 나며 반동 피해. 웅크리기(살금)는 느려지는 대신 받는 피해 절반
- 갈래 특성: 갑옷 받는 피해 -20%, 사냥 물기 +20%·빠름, 무리 회복 2배, 독 물면 중독, 거미 물면 느려짐
- 감싸기: 내 몸으로 한 바퀴(약 35마디부터) 감싸면 1초 뒤 고리 안 곤충을 압착(한 방 필살기)
- 목숨 3개: 쓰러지면 단계는 그대로, 길이 절반으로 3초 무적 부활
- 길이 제한 없음: 길수록 성장이 느려지고 몸이 굵어진다
- 탈피 카드 3장(주변 상성 정보 표시) · 같은 갈래로 이어 가면 숙련(스킬 쿨다운 감소)
- 봇 15마리, 천적 새(그림자 급강하), 5단계가 되면 보스 왕지네 등장 → 쓰러뜨리면 승리

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 게임 로직 자동 점검(화면 없이)
npm run build    # dist/index.html 한 파일로 빌드
```

시험용 주소 옵션: `?stage=3`(3단계로 시작, 5면 보스 바로 등장), `?local=1`(시뮬레이션을 메인 스레드에서 돌림)

## 조작

- PC: 마우스 방향 · 왼쪽 클릭/스페이스 부스트 · Shift 살금 · E/오른쪽 클릭 스킬 · 1/2/3 탈피 카드
- 모바일: 화면 끌기(조이스틱) · 부스트/살금/스킬 버튼 · 카드 누르기

## 구조

- `src/shared/` — 게임 로직(시뮬레이션). 화면을 모르며 Web Worker·서버·테스트에서 그대로 돈다.
  - `config.ts` 밸런스 값, `species.ts` 갈래·종·스킬 데이터(곤충 추가 = 데이터 한 덩어리), `sim.ts` 시뮬레이션, `bot.ts` 봇·보스 AI, `rng.ts` 시드 고정 난수
- `src/client/` — 화면(PixiJS)과 조작. 시뮬레이션이 보낸 상태를 보간해서 그리기만 한다.
- `test/` — 로직 자동 점검

## 글꼴

Jua, Black Han Sans (Google Fonts, SIL Open Font License 1.1). 게임에서 쓰는 글자만 남겨 `src/client/fonts/`에 넣었다.
문구나 종 이름을 새로 쓰면 원본 TTF를 받아 `python3 scripts/subset-fonts.py <원본 폴더>`를 다시 돌린다.
