# 기술 모션 작업법

기술의 손맛은 "예고 → 발동 → 타격 → 여운" 네 단계에서 나온다. 기술 하나를 고칠 때 아래 순서를 따른다.

## 1. 모션 시트 (먼저 글로)

| 단계 | 몸·부품 | 높이 | 화면 | 소리 | 맞은 쪽 |
|---|---|---|---|---|---|
| 예고 | 웅크림, 머리 숙임 | - | 힘 모으는 빛 | windup | - |
| 발동 | 늘어남, 잔상 | 뜸 | 흙먼지 | dash | - |
| 타격 | - | - | 히트스톱, 흔들림 | slam | 번쩍, 넉백, 들림 |
| 여운 | 착지 눌림 | 내려옴 | 금, 흙먼지 고리 | land | 떨어져 쿵 |

합격 기준: 글자를 가리고 봐도 기술 이름을 맞힐 수 있는가.

## 2. 어디를 고치나

- 시뮬레이션(규칙): `src/shared/skills.ts`
  - `windup(sim, s, 초, 이름, fn)`: 예고 동작 뒤에 발동
  - `sim.hitstop(a, b, 초)`: 플레이어가 낀 큰 타격에서 세상이 잠깐 멈춤
  - `sim.fx(kind, s, x, y, { dur, wk })`: 몸 동작 신호. `dur` = 동작 길이, `wk` = 세부 동작 이름
- 몸 동작(자세): `src/client/motion.ts`의 `PROGS`. 시간(0~1)에 따른 높이·늘어남·두께·머리 크기·날개·다리 등
- 이펙트: `src/client/renderer.ts`의 `motionFx()`. 흙먼지(`dustRing`), 금(`cracks`), 충격파(`shockwave`, pixi-filters)
- 소리: `src/client/sfx.ts`의 `fxSound()`와 합성 소리

## 3. 확인 (필름 띠)

도감 미리보기 서버를 켜고 기술 하나를 한 장씩 찍어 격자 이미지로 본다.

```
npm run codex
npx vite preview --config vite.codex.config.ts --port 4174 &
node scripts/filmstrip.mjs <종 id> <atk|def|spc|ult> /tmp/out.png [장수 16] [간격 0.05] [시작 0.3]
```

도감에서는 🐢 버튼으로 0.5배·0.25배 느리게 볼 수 있다.
