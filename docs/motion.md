# 기술 모션 작업법

기술의 손맛은 "예고 → 발동 → 타격 → 여운" 네 단계에서 나온다. 기술 하나를 고칠 때 아래 순서를 따른다.

## 1. 모션 시트 (먼저 글로)

| 단계 | 몸·부품 | 높이 | 화면 | 소리 | 맞은 쪽 |
|---|---|---|---|---|---|
| 예고 | 웅크림, 머리 숙임 | - | 힘 모으는 빛 | windup | - |
| 발동 | 늘어남, 잔상 | 뜸 | 흙먼지 | dash | - |
| 타격 | - | - | 히트스톱, 흔들림 | slam | 번쩍, 넉백, 들림 |
| 여운 | 착지 눌림 | 내려옴 | 금, 흙먼지 고리 | land | 떨어져 쿵 |

합격 기준: 글자를 가리고 봐도 기술 이름을 맞힐 수 있는가.

## 2. 어디를 고치나

- 시뮬레이션(규칙): `src/shared/skills.ts`
  - `windup(sim, s, 초, 이름, fn)`: 예고 동작 뒤에 발동
  - `sim.hitstop(a, b, 초)`: 플레이어가 낀 큰 타격에서 세상이 잠깐 멈춤
  - `sim.fx(kind, s, x, y, { dur, wk })`: 몸 동작 신호. `dur` = 동작 길이, `wk` = 세부 동작 이름
- 몸 동작(자세): `src/client/motion.ts`의 `PROGS`. 시간(0~1)에 따른 높이·늘어남·두께·머리 크기·날개·다리 등
- 이펙트: `src/client/renderer.ts`의 `motionFx()`. 흙먼지(`dustRing`), 금(`cracks`), 충격파(`shockwave`, pixi-filters)
- 소리: `src/client/sfx.ts`의 `fxSound()`와 합성 소리

## 3. 확인 (필름 띠)

도감 미리보기 서버를 켜고 기술 하나를 한 장씩 찍어 격자 이미지로 본다.

```
npm run codex
npx vite preview --config vite.codex.config.ts --port 4174 &
node scripts/filmstrip.mjs <종 id> <atk|def|spc|ult> /tmp/out.png [장수 16] [간격 0.05] [시작 0.3]
```

도감에서는 🐢 버튼으로 0.5배·0.25배 느리게 볼 수 있다.

## 4. 1단계에서 한 것 (2026-11-25)

딱정벌레(돌진, 버티고 밀기, 퍼 올리기, 대지 진동 돌진, 헤라클레스 묵직한 착지)와 잠자리(급강하, 짧은 비행, 낚아채기, 하늘 사냥).

## 1단계 2차 피드백 반영 (2026-11-25)
- 돌진/가위 닫기: 머리 앞 뿔 빛 쐐기를 키우고(길이 2.0~2.4×, 폭 0.45×), 가위는 양쪽에서 휘둘러 닫히는 초승달 + X 베기.
- 버티고 밀기: 머리 앞 연(kite)형 방패 + 몸통 육각 실드 유지, 방패 크기 1.45×.
- 퍼올리기: 상대를 더 높이(z 115) 들어 올리고 위로 솟는 속도선.
- 급강하: 30% 이후 날개를 접고 내리꽂음(wingFold) + 착지 충격파.
- 짧은 비행: 가까운 적 반대쪽으로 비스듬히 뜬 뒤 35% 지점에서 급선회(회피).
- 낚아채기: 첫 적중 시 내 돌진을 멈추고 상대를 내 앞으로 끌어옴 + 줄/집게 연출.
- 겹눈: 시전자 눈에 육각 겹눈 발광 + 주변 적에게 육각 조준 표식.
- 맴돌기: 0.75초 지점에서 회전 방향을 뒤집어 8자 + 날개 기울임.
- 살짝 비키기: 진행 방향의 직각(옆)으로 구르기, 몸 폭 진동.
- 물수제비: 앞쪽 삼각형 세 꼭짓점에 차례로 착지 → 삼각형 범위 전체 피해·기절.

## 1단계 3차 + 사마귀 (2026-11-25)
- 뿔 키우기: 뿔을 머리판과 별도 텍스처(`HeadKit.horn`)로 한 벌 더 만들어, 돌진·가위 예고 때 같은 모양을 1.85배까지 키운다(`Pose.horn`). 사슴벌레 큰턱도 같은 값으로 커진다.
- 집어 던지기: 잡는 쪽 `heft`(물고 머리 들기) → `fling`(뒤로 젖혀 던짐), 잡힌 쪽 `held`(낮게 들림, z 40) → `tossed`(머리 위로 호를 그리며 뒤로) → `slammed`. 날아가는 동안 몸 충돌 없음(flyT).
- 사마귀 낫: `Pose.armL/armR/armScale`. 넓게 베기는 0.12초 예고(`windup:sweep`)로 낫을 치켜든 뒤 휩쓸기, 연속 베기는 L→R→X(양쪽). 휘두를 때 낫 잔상.
- 날개 펼쳐 위협: `Pose.wingBig` — 날개를 직각까지 펴고 2배 이상 키움 + 넓은 날개막·날개맥 + 보라 눈알 무늬.
- 위장: 몸·그림자를 지우고 그 종의 몸 색 잎을 몸 둘레에 흩뿌림. 풀리면 잎이 흩어진다.
- 꽃 흉내 미끼: 들판 꽃과 같은 모양의 분홍 꽃(살랑임), 놓을 때 꽃잎 흩뿌림(`baitset`).
- 마른 잎 죽은 척: 2초 동안 마른 잎이 바깥에서 날아와 몸 둘레를 감싼다.

## 4차: 잠자리 보강 + 지네·벌 1차 (2026-11-25)
- 급강하: 예고 0.24초 동안 큰 날개를 펴고 z 150까지 솟구친 뒤 날개를 접고 내리꽂음. 아주 높을 때 원근 확대는 완만하게(`hzOf`).
- 짧은 비행: 290 거리, 22% 지점에서 거의 직각(1.7rad)으로 꺾음.
- 낚아채기: 나는 제자리. `aimline` 점선 줄(0.3초) → `snatchPull`로 줄 위 적(최대 3)·먹이를 내 앞으로.
- 살짝 비키기: `Snake.slideT`로 경로 전체를 옆으로 150 밀어 꼬리까지 비킴 + 0.32초 무적.
- 꽃 흉내 미끼: 앞쪽 양 대각선(±0.75rad)에 2송이.
- 예고 동작은 본 동작이 이어받을 때까지 끝 자세로 0.12초 버팀(사이 프레임 빠짐 방지).
- 지네: `Pose.coil`(아르키메데스 나선 똬리), `Pose.wrap`(적 둘레 1.5바퀴 감기, 렌더러 `wrapAt`), `Pose.legWhip/legWave`(다리 늘여 물결 채찍), 독턱(forcipule) 벌림·확대. 스크립트에 `moveDelay`, fx의 `wk/dur/on` 추가.
  - 독턱 찌르기 = 움츠림→튀어나감, 몸 말기 = 똬리, 휘감기 = 적 둘레 감기, 긴 다리 채찍 = 다리 채찍(`legwhip`), 치켜들어 덮치기 = 코브라처럼 들기→내리꽂기, 노린내 분비 = 말기+마디마다 분사+얼룩(`stain`), 빛 점액 = 머리 들어 덩이를 호로 뱉기.
- 벌: 연사 = 정지 비행+발마다 반동, 저격 = 조준선 0.35초→큰 반동, 꿀 = 떠서 꿀방울, 경보 = 머리 들고 날개 세게, 열 공 = 부르르, 붕붕 진동 = 온몸 떨림, 진흙 항아리 = 머리 젖혔다 던지기.

## 5차: 지네·벌 보강 + 개미·거미·나비 1차 (2026-11-25)
- 독턱 찌르기: 독턱 끝 초록 독방울·독 김, 맞은 자리 초록 독 연기·거품.
- 백족 소용돌이: `stampede`(다리를 길게 펴 물결치며 내달림) + 땅에 다리 자국, 회전하는 나선 팔 4개.
- 꿀 나누기: 웅덩이 안 꿀 방울 고임·반짝 + 위에서 꿀이 뚝뚝 떨어져 철퍽 고리.
- 열 공: `drawBee` 작은 벌 14마리가 시전자에게서 날아가 3개 궤도로 적을 감쌈(장판도 같은 벌).
- 진흙 항아리: 울퉁불퉁 출렁이는 진흙 덩이 + 흘리는 방울 → 철퍽 진흙 얼룩·튀는 덩이.
- 저격: `bigsting`을 큰 벌침 모양 총알(검은 침 + 주황 띠 + 긴 흰 꼬리 + 공기 고리)로.
- 개미: 산 쏘기 예고·반동, 굴 파기 `dig`(파고들며 흙)→`emerge`, 부르기 `call` + `antrun`(개미 줄이 표적까지), 잎 방패(머리 앞 큰 잎, 잎맥 빛), 도약 침(웅크림→점프→침 + 독), 둥지(흙 파기).
- 거미: 줄 쏘기 반동 + 맞으면 `reel`(뒤로 당김)·적 `yank`, 덫줄 실 뭉치 그림, 그물 `weave`, 줄 타고 빠지기 `recoil` + 팽팽한 실, 껑충 덮치기(웅크림→점프), 새끼 흩기 `spiderlings`(새끼거미 26마리 흩어짐), 독니 `venom`(송곳니 확대 + 붉은 독 방울).
- 나비: 날개 `wingBig`(활짝·크게, 날갯짓 멈춤)·`wingFold`(꽉 접기) 지원. 인분 = 접었다 확 펴기, 팔랑 비행 = 떠서 흔들기, 홀리기·쓴 독 몸·눈알 무늬·푸른 섬광·독털 = 날개 펼치기/떨기.

## 6차: 벌·개미·나비 보강 + 상태 정리 (2026-11-25)
- 열 공: 도감에서 사거리 밖이라 '빗나감' 연출이 내 앞에서 돌던 문제 → 도감은 170 안에서 쓰고, 빗나가면 벌이 앞으로 흩어지기만 한다.
- 개미 부르기: 진짜 소환수 `ant` 4마리(시뮬레이션 미니언)가 걸어가 적을 문다. 물 때 큰턱이 쩍 + 흰 '딱' 별.
- 군단 진군: 붉은 병정개미 `soldier` 12마리가 내 몸 양옆에 두 줄로 붙어 행진하고, 가까이 온 적에게 뛰쳐나가 문다(`soldierTick`).
- 인분: 3초 남는 반짝이 가루 구름 덩이. 나비 떼 폭풍: 색색 나비 36마리 3겹 회오리. 독털: 굵은 털 + 초록 독 끝 + 초록 독 안개.
- 상태: `src/shared/status.ts`의 `STATUSES`(이상 13 · 강화 10)가 기준. 스냅숏 `st`로 남은 시간 전달 → 머리 위 아이콘(이상 빨간 테, 강화 초록 테, 지속시간 시계 덮개, 0.5초 남으면 깜빡). 혼란·매혹·가려움 타이머(`confuseT/charmT/itchT`)를 곤충에 추가. 도감 '3판 표'에 상태 정리 표.
