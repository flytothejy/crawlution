# 밸런스 분석 메모

자동 보고서(`docs/balance.md`, `balance/out/report.html`)를 읽고 원인을 확인해 내린 판단을 적는다.
측정 방법은 `balance/README.md`.

## 2026-11-26 · 1차 심층 분석

### 기준선에서 본 것

- **1:1 결판이 4~5초.** 기술 재사용 대기(9~14초)보다 짧아서 한 판에 기술을 한 번씩만 쓴다 → '첫 한 바퀴 폭딜'이 승부를 정한다.
  - 가설 검증: 체력을 전체 1.5배로 올리면 결판 시간은 4.1초 → 6.1초가 되지만, 종 승률 표준편차는 0.179 → 0.172로 그대로.
  - 결론: 전투 속도가 아니라 종·기술별 문제. 전체 체력은 그대로 두고 원인 기술을 고친다.
- **필살기는 1:1 승부에 거의 영향이 없다**(판당 0.01~0.08회). 필살기 밸런스는 아레나 판으로 본다.
- **실전 적중률**(1:1에서 한 번 썼을 때 들어간 피해 ÷ 실측 한 방 피해)이 기술마다 크게 다르다.
  - 0.4~0.6: 대부분의 직선·부채꼴 기술.
  - 1.0 이상: 피할 수 없는 기술(개미 부르기 등).

### 측정으로 못 재는 기술

위장·경보 페로몬·꿀 나누기·겹눈·독니 깨물기처럼 다음 공격을 강화하거나 아군을 돕는 기술은 한 번 쓰는 실측에서 효과가 안 보인다.
보고서는 이들을 '실측 밖'으로 따로 표시한다. 세기는 1:1·아레나 성적으로 판단한다.

### 남은 과제

- **잠자리 1:1이 여전히 낮다.** 아레나 판 순위는 중간 이상(51% → 61%)이라 실제 게임에서는 문제가 크지 않다. 원인은 봇 판단(탈출기를 시작부터 씀, 탱커를 끌어옴) 쪽이 크다. 봇 기술 판단을 다듬으면 다시 잰다.
- **플레이어 자리 이점.** 같은 봇 AI로 돌려도 플레이어 자리가 평균 1.4등이었다. 점수를 판 전체 누적으로 바꾼 뒤에도 1~3등이 잦다. 원인은 규칙 차이로, 플레이어는 쓰러져도 레벨·카드를 지키고 봇은 평균 레벨−2로 새로 시작한다.
