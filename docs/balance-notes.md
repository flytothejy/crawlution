# 밸런스 분석 메모

자동 보고서(`docs/balance.md`, `balance/out/report.html`)를 읽고 원인을 확인해 내린 판단을 적는다.
측정 방법은 `balance/README.md`.

## 2026-11-26 · 1차 심층 분석

### 기준선에서 본 것

- **1:1 결판이 4~5초.** 기술 재사용 대기(9~14초)보다 짧아서 한 판에 기술을 한 번씩만 쓴다 → '첫 한 바퀴 폭딜'이 승부를 정한다.
  - 가설 검증: 체력을 전체 1.5배로 올리면 결판 시간은 4.1초 → 6.1초가 되지만, 종 승률 표준편차는 0.179 → 0.172로 그대로.
  - 결론: 전투 속도가 아니라 종·기술별 문제. 전체 체력은 그대로 두고 원인 기술을 고친다.
- **필살기는 1:1 승부에 거의 영향이 없다**(판당 0.01~0.08회). 필살기 밸런스는 아레나 판으로 본다.
- **실전 적중률**(1:1에서 한 번 썼을 때 들어간 피해 ÷ 실측 한 방 피해)이 기술마다 크게 다르다.
  - 0.4~0.6: 대부분의 직선·부채꼴 기술.
  - 1.0 이상: 피할 수 없는 기술(개미 부르기 등).

### 2~4차 조정(잡음을 고려해 측정 세 번 연속 바깥쪽인 종만)

아레나 판 40번으로도 종 하나의 강함 지수는 측정마다 ±0.5쯤 흔들린다(바꾸지 않은 넓적배사마귀가 −0.73 ~ −1.64). 그래서 한 번만 튄 종은 건드리지 않았다.

| 종·기술 | 조정 |
|---|---|
| 개미 부르기 | 지속 4초 → 3.5초 |
| 깡충거미 | 껑충 덮치기 피해 ×0.75 → ×0.65. 본능 자동 도약 피해 0.5 → 0.3, 4초에 한 번만 |

| 딱정벌레 돌진 | 피해 ×0.85 → ×1.05 |
| 거미 계열 | 체력 1.0 → 1.12 |
| 늑대거미 | 본능 질주 +10% → +15%, 새끼 흩기에 물기 피해(기본 ×0.4) + 느려짐 2.5초 |
| 왕거미 줄 타고 빠지기 | 재사용 8초 → 6초, 지나온 길에 1.5초 끈끈한 줄(측정 5번 내내 최하위권) |
| 군대개미 군단 진군 | 병정개미 피해 0.28 → 0.11(12마리 유지). 0.2일 때도 실전 분당 피해가 일본왕개미 필살기의 3.5배 — 처치 → 게이지 → 다시 진군의 눈덩이. 실전 피해의 21%가 필살기 — 같은 계열 일본왕개미는 9%. 실측은 허수아비가 제자리라 낮게 나옴 |

| 난초사마귀 꽃 미끼 | 피해 0.2 → 0.3 |
| 제왕나비 쓴 독 몸 | 2초·40% → 3초·50%(각성 75%) |

그 밖에: 데굴 구르기 방향이 `Math.random()`이라 같은 시드에서도 결과가 달랐다 → 판의 난수(`sim.rng`)로 바꿈(측정 재현성·멀티플레이 동기화).

### 측정으로 못 재는 기술

위장·경보 페로몬·꿀 나누기·겹눈·독니 깨물기처럼 다음 공격을 강화하거나 아군을 돕는 기술은 한 번 쓰는 실측에서 효과가 안 보인다.
보고서는 이들을 '실측 밖'으로 따로 표시한다. 세기는 1:1·아레나 성적으로 판단한다.

### 남은 과제

- **잠자리 1:1이 여전히 낮다.** 아레나 판 순위는 중간 이상(51% → 61%)이라 실제 게임에서는 문제가 크지 않다. 원인은 봇 판단(탈출기를 시작부터 씀, 탱커를 끌어옴) 쪽이 크다. 봇 기술 판단을 다듬으면 다시 잰다.
- **플레이어 자리 이점.** 같은 봇 AI로 돌려도 플레이어 자리가 평균 1.4등이었다. 점수를 판 전체 누적으로 바꾼 뒤에도 1~3등이 잦다. 원인은 규칙 차이로, 플레이어는 쓰러져도 레벨·카드를 지키고 봇은 평균 레벨−2로 새로 시작한다.

## 2026-11-26 · 전투 시간 기준과 생존

### 전투 시간 기준(`balance/weights.ts`의 `TARGET`)

| 지표 | 목표 | 왜 |
|---|---|---|
| 1:1 결판 시간(같은 레벨, 정면, 체력 가득) | 7~10초 | 공격 기술 재사용 8~10초 → 공격 기술을 두 번쯤, 방어·특수를 한 번씩 주고받는 싸움 |
| 붙잡혀 쓰러지기까지(아레나) | 4~9초 | 알아채고(0.5~1초) 방어 기술·웅크리기·질주로 대응할 틈 |
| 붙잡힌 뒤 살아남음 | 35~60% | 붙잡히면 위험하지만 끝은 아님 |
| 쓰러질 때 제어에 묶인 비율 | 30% 이하 | 손도 못 쓰고 죽는 판이 많으면 안 됨 |

조정 손잡이는 `CONFIG.hpScale`(전체 체력 배율) 하나. 공격 수치는 그대로 두고 체력만 곱한다(천적 피해·회복은 최대 체력 비율이라 같이 따라감).

| 체력 배율 | 1:1 결판 | 쓰러지기까지 | 2초 안에 쓰러짐 |
|---|---|---|---|
| 1.0(전) | 4.4초 | 3.8초 | 24% |
| 1.5 | 6.9초 | 5.4초 | 15% |
| 1.8 | 9.1초 | 6.6초 | 10% |
| 2.0 | 10.0초 | 6.9초 | 8% |

→ **1.6**(처음 1.7로 정했다가 전체 측정에서 1:1이 10.1초로 살짝 넘어 1.6으로). 체력 배율은 종 사이 격차를 바꾸지 않는다(1:1 승률 편차 0.15~0.16 그대로).
제어에 묶인 비율은 처음부터 17%로 목표 안 — '맞기 시작하면 죽는' 원인은 제어 고리가 아니라 피해 속도였다.

### 방어 기술이 살려 주나(4층 탈출 실험)

아레나에서 '방어 기술을 쓴 교전의 생존율'은 질 때 꺼내는 기술일수록 낮게 나와(선택 편향) 효과를 잴 수 없었다.
→ 통제 실험: 체력 35%로 쫓길 때 방어 기술이 준비된 경우 vs 대기 중인 경우의 10초 생존율 차이.

처음: 대기 중 생존 20%, 방어 기술의 평균 기여 약 8%p. 몸 말기 −14%p(멈춰 서서 −40%만 받음), 줄 타고 빠지기 −4%p(뒤로 = 쫓아오는 적 쪽으로 뛰어듦), 잎 방패 −4%p(앞쪽만 막음 — 쫓기면 뒤에서 맞음), 버티고 밀기 0%p(앞쪽만 밂, 봇이 위기에 17%만 씀).

조정:
- **방어 칸 공통 '몸 추스르기'**: 방어 기술을 쓰면 느려짐·묶임 해제 + 1.2초 이동 속도 +30%(`CONFIG.rallyTime`·`rallySpeed`).
- 봇: 쫓기며 체력 40% 아래면 방어 기술을 종류와 상관없이 꺼낸다.
- 몸 말기 −40% → −70%, 풀릴 때 밀쳐 내기(각성 없이도) + 몸 추스르기.
- 줄 타고 빠지기: 가까운 적의 반대쪽으로. 잎 방패: 옆·뒤도 −40%.
- 버티고 밀기: 가까운 적을 향해 돌아서고 −30% → −50%, 밀기 40 → 55, 끝나면 몸 추스르기.
- 꿀 나누기: 꿀이 나를 따라다님, 회복 4 → 5%/초. 위협: 공포 1 → 1.3초, 범위 160 → 180. 새끼 흩기: 1초 숨기.

결과: 방어 기술 평균 기여 25%p. 탈출형(짧은 비행·굴 파기·팔랑 비행·죽은 척) 33~46%p, 버티는 형 12~23%p.

### 부활

- 플레이어·봇 같은 규칙: 레벨·카드·필살기 게이지 유지, 길이 절반(봇은 전에 평균 레벨−2로 새로 시작 → 같은 봇 AI로 돌려도 플레이어 자리가 평균 1.4등).
- 자리: 다른 곤충의 머리·몸·장판에서 900 넘게 떨어진 곳(40번 찾아 가장 먼 곳), 가장 가까운 적을 등지고 나온다.
- 3초 무적(봇도). 먼저 공격(기술·물기)하면 바로 풀린다.

### 싸움이 길어지며 바뀐 판도

체력 ×1.7·생존 강화 뒤 전체 측정: 한 방이 강한 사마귀(1:1 49% → 30%)와 처치력이 약한 나비·딱정벌레가 내려가고, 오래 버티며 회복하는 벌(K/D 0.93 → 1.33)·개미가 올라갔다. 짧은 싸움에서는 폭딜이, 긴 싸움에서는 지속 피해·회복이 유리.
→ 사마귀 공격 1.2 → 1.3, 나비 1.0 → 1.1, 장수풍뎅이 1.1 → 1.2, 꿀 회복 5 → 4%/초(따라다니기는 유지).

### 웅크리기

없앤 적 없다. 받는 피해 절반(`guardMul`), 이동 55%. 사마귀 '매복', 왕사마귀 '기도 자세', 넓적배사마귀 '버티기' 등이 웅크리기를 쓴다.
