# 3판 전환 메모

게임은 3판 명단(8계열 40종)으로 돈다. `GameOpts.v3 = true`(클라이언트가 켠다). 기본값은 false라 2판 테스트·도감 2판 탭은 그대로다.

## 기술 4칸

| 칸 | 키 | 해금 | 쿨 필드 |
|---|---|---|---|
| 공격 | E / 우클릭 | Lv1 | `skillCd` |
| 방어 | Q | Lv3 | `subCd` |
| 특수 | W | Lv5 | `spcCd` |
| 필살기 | F | 게이지 | `ult` |

- `kit.ts`: 종마다 4칸을 정한다. `play.real`이 있으면 2판 엔진 기술(`main`/`sub`/`ult`)을 부르고, 없으면 `skills3.ts`의 새 기술(`new`/`newult`)을 부른다.
- 2판 계열(엔진 계열)은 능력치·특성·카드에 그대로 쓰고, 화면·명단은 3판 계열(`v3fam`)로 묶는다.
- 새 엔진 계열: centipede, ant, butterfly (`NEW_FAMILIES`).

## 누가 일으켰나(`sim.actor`)

딱정벌레 특성(기절 +0.2초, 밀어내기 1.2배)처럼 "누가 건 효과인지"가 필요한 규칙은 `sim.actor`로 판단한다. `sim.as(who, fn)`, `later()`, 텔레그래프, 투사체 적중, 돌진 적중, 장판, 소환수가 모두 actor를 넘긴다.

## 상태

`status.ts`의 23종(이상 13, 강화 10)이 sim 타이머를 그대로 읽는다. 도감 시연의 아이콘도 실제 기술로 걸린 상태다.

## 검증

`test/v3.test.ts`: 데이터, 20봇 한 판, 칸마다 기술 발동·적중, 상태 17종 이상 실제로 걸림, 계열 특성·본능.

## 밸런스 1차 (2026-11-26)

`npx tsx scripts/balance3.ts [판 수] [시작 시드] [출력.json]` — 21마리 모두 봇 AI로 5분 판을 돌려 종별 처치·쓰러짐·피해·생존을 모은다(2코어에서 12판 ≈ 5분).

24판 기준 계열 K/D(처치 ÷ 쓰러짐):

| 계열 | 시작 | 조정 후 |
|---|---|---|
| 개미 | 3.02 | 1.56 |
| 지네 | 1.25 | 1.22 |
| 벌 | 1.05 | 1.13 |
| 사마귀 | 1.00 | 0.97 |
| 거미 | 0.80 | 0.91 |
| 딱정벌레 | 0.80 | 0.77 |
| 잠자리 | 0.60 | 0.75 |
| 나비 | 0.40 | 0.67 |

조정:
- 개미 부르기: 개미 한 마리 피해 B×0.35 → 0.13, 지속 5초 → 4초(4마리 유지). 이 기술 하나를 끄면 개미 K/D가 1.0으로 떨어졌다(원인 확인 실험).
- 군단 진군: 병정개미 피해 B×0.45 → 0.28. 일개미 함께 물기: 마리당 20% → 10%. 굴 파기 무적 0.95초 → 0.75초.
- 나비 계열: 체력 0.85 → 1.0, 공격 0.9 → 1.0, 밀려남 1.2 → 1.1. 인분 구름 B×0.28 → 0.45/초, 나비 떼 폭풍 0.35 → 0.45/초, 독털 B×0.5 → 0.7.
- 잠자리 엔진 계열 체력 0.8 → 0.88, 장수풍뎅이 엔진 계열 공격 1.0 → 1.1, 거미 엔진 계열 공격 1.0 → 1.08.

남은 것: 종 단위 편차(불독개미·땅지네 높음, 늑대거미·왕나비 낮음)는 표본이 작아(종당 50~150생) 다음 판에서 판 수를 늘려 본다.
